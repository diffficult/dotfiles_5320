# yazi

Laptop-side (poole) yazi file manager config. Mirrored from the desktop
live config on 2026-06-25.

## Setup on a fresh machine

After this directory lands in `~/.config/yazi/`:

```sh
ya pkg install
```

This downloads and links every plugin listed in `package.toml`. No
manual cloning required.

## First-time gotchas

1. **Catppuccin-macchiato flavor** — `theme.toml` references this
   flavor, but the flavor file is custom and lives only on the desktop
   at `~/.config/yazi/flavors/catppuccin-macchiato.yazi/flavor.toml`.
   Either copy that directory over, or change `theme.toml` to a stock
   yazi flavor.

2. **Kitty graphics protocol** — image previews only render in tmux if
   `~/.tmux.conf` has `set-option -g allow-passthrough on` and the
   Kitty terminal is configured accordingly. See comment block at the
   top of `yazi.toml`.

3. **Dead keybinds** — `keymap.toml` binds `z` → `plugin zoxide` and
   `Z` → `plugin fzf`, but neither plugin is declared in `package.toml`
   (they aren't installed on the desktop either). See commented blocks
   at the bottom of `package.toml` for the two options to resolve.

## What is NOT in this repo (and why)

| File / dir | Why omitted |
|---|---|
| `plugins/` | Auto-generated by `ya pkg install`. Commit only `package.toml`. |
| `flavors/` | Custom and desktop-personal. Copy manually if needed. |
| `init.lua` | Desktop has personal plugin setup (full-border rounded, searchjump colors, yaziline, starship). The laptop can opt-in by copying it. |
| `yazi.toml.bak` | Local backup, never needed elsewhere. |
| `.claude/` | Agent local state. |

## Updating from desktop

1. On desktop, run `ya pkg list` to refresh lockfile.
2. Copy `~/.config/yazi/yazi.toml`, `keymap.toml`, and `package.toml`
   here.
3. Diff and commit. Never touch `theme.toml` — paths are laptop-specific
   (`/home/poole/...`).
